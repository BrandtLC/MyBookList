# MyBookList 📚

MyBookList é uma aplicação web que permite ao usuário buscar livros através da Google Books API, marcar quais já leu e atribuir notas.

---

## 🚀 Tecnologias utilizadas

- **Frontend:** React + Vite
- **Backend:** Flask (Python)
- **API externa:** Google Books API
- **Containerização:** Docker e Docker Compose

---
